## 👤 Overview

**EduTrack** is a lightweight, single-file web app for managing student **attendance, marks, timetables, and announcements** — built for both **Teachers** and **Students**.

There's no backend, no build tooling, and nothing to install. The entire application — markup, styling, and logic — lives in one HTML file that runs directly in the browser or deploys instantly to GitHub Pages.

<br>

## 🧩 Problem Statement

Many colleges still rely on manual attendance registers, scattered mark sheets, and WhatsApp groups for announcements. This makes it hard for:

- **Teachers** to quickly compute attendance percentages, enter marks, and keep a class updated.
- **Students** to get a clear, real-time view of their own attendance, grades, and schedule.
- **Both roles** to access this information without installing an app or relying on a paid platform.

> **Goal:** Provide a zero-setup, single-file portal that gives teachers fast administrative tools and gives students instant visibility into their own academic standing.

<br>

## ✨ Features

| Feature | Description |
|---|---|
| 🔐 Role-based login | Separate dashboards and permissions for Teachers and Students |
| 📊 Attendance tracking | Mark present/absent per class, view monthly breakdowns and live percentages |
| 📝 Marks & grades | Record exam scores per subject, auto-calculated GPA, grade badges |
| 🕒 Timetable view | Weekly schedule organized by department and semester |
| 📢 Announcements | Post and view department-specific or general notices |
| 📈 Visual dashboards | Attendance and performance charts powered by Chart.js |
| 📱 Responsive design | Collapsible sidebar and mobile-friendly layout across screen sizes |

<br>

## 👥 Role-Based Workflows

**Teacher**
1. Logs in with teacher credentials.
2. Selects department & semester to load the class list.
3. Marks daily attendance or enters exam marks for a subject.
4. Posts announcements visible to the relevant students.
5. Reviews class-wide attendance % and performance charts.

**Student**
1. Logs in with student credentials.
2. Views personal attendance history and running percentage.
3. Checks subject-wise marks and auto-calculated GPA.
4. Views the weekly timetable for their department/semester.
5. Reads announcements posted by teachers.

## 🚀 Getting Started

No build steps or dependencies to install — it's a single HTML file.

**1. Clone the repository**
```bash
git clone https://github.com/irfanshafi21/edutrack.git
cd edutrack
```

**2. Run it locally**

Open `attendance.html` directly in your browser — double-click the file or drag it into a browser tab. No local server required.

**3. Or deploy with GitHub Pages**

1. Push the repo to GitHub (already done for this project).
2. Go to **Settings → Pages** in the repository.
3. Set the source branch to `main` (root).
4. GitHub Pages will publish the file at the URL below.

## 📂 Repository Structure

```text
edutrack/
└── attendance.html   # Full app — markup, styles, and logic in one file
```

**About `attendance.html`**
- Self-contained: no external build config, package.json, or server needed.
- Loads Tailwind CSS, Chart.js, and Font Awesome via CDN `<script>`/`<link>` tags.
- All UI state (login role, active tab, chart data) is managed with vanilla JavaScript in the same file.
- Designed to be easy to fork and extend — add a new tab, a new chart, or a new data field directly in the markup/script without touching a build pipeline.

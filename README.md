# EduTrack 🎓

A lightweight, single-file web app for managing student **attendance, marks, timetables, and announcements** — built for both **Teachers** and **Students**.

![Status](https://img.shields.io/badge/status-active-brightgreen) ![Made with](https://img.shields.io/badge/made%20with-HTML%2FJS-blue)

## ✨ Features

- 🔐 **Role-based login** — separate dashboards for Teachers and Students
- 📊 **Attendance tracking** — mark present/absent, view monthly breakdowns and percentages
- 📝 **Marks & grades** — record exam scores, auto-calculated GPA, subject-wise performance charts
- 🕒 **Timetable view** — weekly schedule by department and semester
- 📢 **Announcements** — post and view department-specific or general notices
- 📈 **Visual dashboards** — attendance and performance charts powered by Chart.js
- 📱 **Responsive design** — collapsible sidebar and mobile-friendly layout

## 🛠️ Built With

- **HTML5 / CSS3 / Vanilla JavaScript**
- [Tailwind CSS](https://tailwindcss.com/) (via CDN)
- [Chart.js](https://www.chartjs.org/) — for attendance & marks visualizations
- [Font Awesome](https://fontawesome.com/) — icons
- Google Fonts (Inter)

## 🚀 Getting Started

No build steps or dependencies to install — it's a single HTML file.

1. Clone the repo:
   ```bash
   git clone https://github.com/irfanshafi21/edutrack.git
   ```
2. Open `attendance.html` directly in your browser, **or**
3. Deploy it instantly with GitHub Pages (see below).
